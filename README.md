# Labyrinth 3D

Небольшая 3D-игра от первого лица: исследуйте лабиринт, соберите все кристаллы и найдите выход. Изображение строится программным ray casting, без игрового движка и сторонних библиотек.

Проект состоит из двух частей: **C++17** генерирует случайные проходимые уровни, а **Java / Swing** загружает карту, рисует 3D-сцену и обрабатывает игру. Компоненты обмениваются текстовым файлом карты; JNI и сервер не нужны.

## Требования

- JDK 17 или новее (команды `java` и `javac`); для игры нужен графический рабочий стол.
- Компилятор C++17 (`g++` или `clang++`).
- Для команд ниже: GNU Make; для тестов также Python 3.

## Быстрый старт (Linux / macOS)

Откройте терминал в корне проекта:

```sh
make
make run
```

В комплекте есть готовая карта `maps/default.map`. Если Make не установлен, аналогичные команды:

```sh
mkdir -p build/classes
c++ -std=c++17 -O2 -Wall -Wextra -pedantic cpp/levelgen.cpp -o build/levelgen
javac -encoding UTF-8 -d build/classes java/MazeGame.java
java -cp build/classes MazeGame maps/default.map
```

### Управление

- **W / S** или **↑ / ↓** — вперёд / назад; **A / D** — движение вбок.
- **← / →** — поворот; **R** — начать текущий уровень заново; **Esc** — закрыть игру.
- Соберите все голубые кристаллы. Выход станет зелёным; зайдите в него, чтобы победить. Оранжевый выход ещё закрыт.

## Свой уровень

```sh
./build/levelgen build/my-level.map 12345
java -cp build/classes MazeGame build/my-level.map
```

Второй аргумент генератора — целый seed от 0 до 4294967295; одинаковый seed воспроизводит одинаковую карту. Генератор перезаписывает указанный файл; его родительский каталог должен существовать. Готовую карту тоже можно редактировать вручную. Подробности формата, архитектуры и устранения неполадок — в [технической справке](TECHNICAL.md).

## Проверка

```sh
make test
```

Тесты выполняются без графического рабочего стола: проверяют генератор, валидатор, рендеринг, сбор кристаллов и победу. Удалить артефакты сборки: `make clean`.
