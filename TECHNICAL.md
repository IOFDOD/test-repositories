# Техническая справка

## Архитектура

- `cpp/levelgen.cpp`: генерирует лабиринт 21×21 алгоритмом поиска в глубину с возвратом. Затем поиск в ширину находит наиболее удалённую от старта клетку для выхода. Три кристалла распределены по порядку обхода. Старт, кристаллы и выход связаны проходами. Генератор использует `std::mt19937` и фиксированное отображение случайных чисел на варианты, поэтому seed воспроизводим.
- `java/MazeGame.java`: проверяет карту, создаёт окно Swing и запускает игровой таймер. Лучи пересекают сетку алгоритмом DDA; перпендикулярная дистанция формирует стены и буфер глубины для спрайтов. Движение учитывает столкновения со стенами, а выход срабатывает только после сбора кристаллов.
- `maps/default.map`: готовый уровень (seed 42). `tests/` содержит автономные проверки генератора, загрузчика и логики игры.

C++-генератор не вызывается игрой автоматически: сначала создайте файл, затем передайте его Java-программе. Это позволяет запускать игру с готовыми или вручную созданными картами без установленного компилятора C++.

## Формат карты

UTF-8, по одной строке на ряд, без пробелов; все строки одинаковой ширины, от 3 до 256 клеток в каждом измерении. Внешняя граница полностью состоит из стен:

| Символ | Значение |
| --- | --- |
| `#` | стена |
| `.` | проход |
| `S` | старт (ровно один) |
| `C` | кристалл (хотя бы один) |
| `E` | выход (ровно один) |

Все кристаллы и выход должны быть достижимы от старта по горизонтальным или вертикальным проходам. Минимальный пример:

```text
#####
#SCE#
#####
```

Проверка без запуска окна:

```sh
java -Djava.awt.headless=true -cp build/classes MazeGame --check maps/default.map
```

При успехе выводится размер и число кристаллов, код выхода — 0. При ошибке программа печатает сообщение в stderr и возвращает ненулевой код. Путь к карте разрешается относительно текущего рабочего каталога.

## Решение проблем

- **`javac: command not found`** — установите JDK, а не только среду выполнения Java, и добавьте его `bin` в PATH.
- **`A graphical desktop is required`** — запуск игры требует рабочий стол. В окружении без дисплея используйте `--check` и `make test`.
- **Ошибка чтения файла** — проверьте путь и права доступа; генератор не создаёт отсутствующие родительские каталоги.
- **Ошибка карты** — проверьте символы, размеры, границу, количество S/E/C и достижимость целей. Сообщение загрузчика уточнит причину.
- **Клавиши не работают** — щёлкните по окну, чтобы вернуть ему фокус. При потере фокуса нажатия сбрасываются.
- **Низкая частота кадров** — уменьшите размер карты или закройте другие приложения: рендеринг выполняется программно на CPU.

Windows: выполните эквивалентные команды сборки через среду с компилятором C++17 и JDK (например, MSYS2); имя генератора будет `build/levelgen.exe`. Текстовые карты работают одинаково на всех платформах.
